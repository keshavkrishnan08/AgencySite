Levers, by impact

where to spend effort
  1. Conversion (land→paid). 1.3% → 2.6% halves CAC. Biggest single lever.
  2. Churn. 22% → 15% lifts LTV ~40%. The metrics page is the tool.
  3. Plan mix. Every point shifted monthly → yearly raises blended LTV.
  4. Channel. Retargeting + lookalikes cut CAC 2–3× vs cold prospecting.

Assumptions & status

Costs. Stripe 2.9% + $0.30 per charge; Claude API + infra ≈ $1.44 / user / month. Monthly churn 22% (active job-seekers).

LTV basis. Contribution margin, not revenue. Term plans modelled as renewing while the user is still searching: (1−churn) compounded over the term.

Funnel. Rates modelled from the 1,000-user Meta-ad ABM. Every step is a wired Mixpanel event (page:view → upgrade_success); the live funnel replaces these estimates the moment ads run.

Payments. Stripe integration built and verified end-to-end in test mode — idempotent webhook, source-of-truth sync, access enforcement. Live keys + activation pending before real charges.
